# SIH 2026 — Slide 4: Our Solution — ORBITGUARD

## Overview
**ORBITGUARD** is a serious, open, and accessible Space Situational Awareness (SSA) and deterministic collision screening platform.

### Core Value Propositions
1. **Zero-Simulation Integrity:** SGP4 analytical propagation using authentic Two-Line Element sets.
2. **Deterministic Conjunction Engine:** Broad-to-narrow multi-scale screening computing exact Time of Closest Approach (TCA) and 3D Euclidean miss distance.
3. **Explainable Risk Scoring:** 0–100 Conjunction Risk Score factoring proximity, hypervelocity kinetic impact potential, and lead time.
4. **Dual Visual Intelligence:** Responsive 2D Equirectangular ground track map for tactical monitoring + 3D Three.js celestial Earth globe for orbital orientation.
5. **Operational Alert Center:** Automated threshold alerting with operator acknowledgment lifecycle.
